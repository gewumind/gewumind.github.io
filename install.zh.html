安装 GewuMind Boot

安装器 v0.1.0 · Linux / Windows / macOS · GUI + CLI

在线体验（中文）：http://47.117.145.234:34567 · 账号 admin / 123456
安装器负责环境检测、空库校验、数据库初始化、JRE 准备、服务注册、升级和卸载。 应用包和数据库包从 GitHub 或 Gitee Releases 下载。 当前安装器覆盖 2.3.0。

先选安装方式

方式适合场景需要 clone 源码你需要准备
直接安装 试用、生产部署、只需要运行现成版本 不需要 安装器 + 对应版本的应用包和数据库包
二次开发 修改内核、增加自定义能力、深度定制 需要 git clone gewumind-boot、JDK 17、Maven 3.8+、MySQL 8

直接安装不需要 clone 源码，也不需要 Maven / Node。 安装器只负责安装已经构建好的发行包，不会替你拉取源码或编译内核。

二次开发请从源码仓库开始： github.com/gewumind/gewumind-boot， 修改后自行构建发行包；安装器可用于安装你构建出来的包。

下载安装器

安装器启动时读取线上版本清单：installer-manifest.json，下拉版本来自清单，不写死在安装器里。新版本发布后更新清单即可。

默认安装目录

平台默认目录
Linux/opt/gewumind-boot（root）；普通用户为 ~/gewumind-boot
WindowsC:\gewumind-boot
macOS/usr/local/gewumind-boot（root）；普通用户为 ~/gewumind-boot

已有 JVM 路径和本地 JRE 包都可以在界面中点击「选择目录」/「选择文件」，也可以直接输入路径。

前置条件

  • MySQL 5.7+ / 8.0+，推荐 MySQL 8；数据库必须存在且为空库。
  • Java 17+。没有时安装器可下载 Temurin JRE 17，或使用 --java-home / --jvm-archive。
  • Linux 安装 systemd 服务需要 root；Windows 需要管理员权限。
  • 建议至少 2GB 可用磁盘。

先创建空库

CREATE DATABASE `gewumind-boot`
  CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

安装器不会创建数据库，也不会覆盖非空库。确认表数为 0：

SELECT COUNT(*) FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'gewumind-boot';

方式一：图形安装向导

Linux / macOS：

chmod +x gw-installer-linux-amd64
sudo ./gw-installer-linux-amd64 gui

Windows：双击 gw-installer-windows-amd64.exe，或在管理员终端运行：

gw-installer-windows-amd64.exe gui

GUI 默认只监听 127.0.0.1，终端会输出带 token 的本地地址。 安装在远程服务器时，请通过 SSH 端口转发访问，不要直接把安装器端口暴露到公网。

方式二：命令行安装

下载应用最小包和数据库包后，以 2.3.0 中文版为例：

sudo ./gw-installer-linux-amd64 install \
  --version 2.3.0 \
  --lang zh \
  --app-package ./gewumind-boot-app-2.3.0-zh-min.tar.gz \
  --db-package ./gewumind-boot-db-2.3.0-zh.tar.gz \
  --install-dir /opt/gewumind-boot \
  --server-port 9089 \
  --db-host 127.0.0.1 --db-port 3306 \
  --db-name gewumind-boot --db-user root

数据库密码会交互询问，输入时不回显；也可以使用 GW_DB_PASSWORD 环境变量。

也可让安装器按 manifest 自动下载应用包和数据库包：

sudo ./gw-installer-linux-amd64 install \
  --version 2.3.0 --lang zh --source auto \
  --db-name gewumind-boot --db-user root

安装后

  • 后台地址默认是 http://服务器IP:9089，默认账号 admin / 123456。
  • Linux 默认注册 systemd 服务并开机自启。
  • 商业能力通过「配置中心 → 上传授权文件」激活；先复制授权申请码再申请。
  • 演示环境可切换 demo profile；上传授权文件前要切回 online。

升级与卸载

# 升级前先备份数据库
sudo ./gw-installer-linux-amd64 upgrade \
  --version 2.3.0 \
  --app-package ./gewumind-boot-app-2.3.0-zh-min.tar.gz \
  --db-package ./gewumind-boot-db-2.3.0-zh.tar.gz

# 卸载：保留数据库
sudo ./gw-installer-linux-amd64 uninstall

升级会保留 License、data 和配置；卸载默认删除安装目录但保留数据库。

验证与说明

Linux 已完成真实安装、升级、卸载验证；Windows Service 与 macOS launchd 已完成适配和交叉编译， 尚未在真实 Windows / macOS 机器上验收。遇到问题时请附上系统版本、安装器版本和日志。

详细参数和更多示例见安装器帮助： gw-installer --help、gw-installer install --help。
