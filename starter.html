Subject: [GW-STARTER] Company/team - Project name. Use one field per line. Write “none” for empty fields; do not remove labels. The system parses these labels, so an invalid format delays processing.

Do not send passwords, private keys, full identity numbers or customer-sensitive data. Desensitize demo data first.

Why start with a small instance

The real risk in a backend system is not drawing pages. It is misaligned requirements, unclear permission boundaries and a data model that is wrong from day one. Build one core module, run a real workflow, then decide whether to invest in the full project.
