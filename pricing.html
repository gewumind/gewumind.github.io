How to request a license

After payment, email gewumind@foxmail.com. Keep the labels unchanged.

Important rules

FAQ

What is the difference between Standard and Enterprise?

Standard includes all commercial capabilities except AI. Enterprise adds AI customer service, knowledge base and H5 support.

Can one machine run multiple instances?

Yes. Licensing is per machine code, not per instance.

Can I still buy 1.x?

No. 1.x is end-of-life; only 2.x licenses are available.

What if my machine code changes?

The existing license cannot be used on the new machine code; a new license is required.
