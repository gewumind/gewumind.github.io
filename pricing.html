FAQ

Can I run multiple instances on one machine?

Yes. The license is bound to the machine code, not to an instance count.

Can I use a 1.x license with 2.x?

No. 1.x and 2.x are separate products and require separate licenses.

What if my machine code changes?

The existing license cannot be used on the new machine code. A new license is required.
