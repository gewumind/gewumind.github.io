它是什么What it is

一个容器，装下整个后端One container for your whole backend

把接口、数据、权限、组件、工作流、消息、AI 能力装进一个开箱即用的 Spring Boot 应用，业务用「配置 + 脚本」表达，而不是重复写样板代码。APIs, data, auth, components, workflow, messaging and AI in one ready-to-run Spring Boot app — business logic expressed as config + scripts, not boilerplate.

接口即脚本APIs as scripts

基于 magic-api，在线编写 HTTP 接口，热更新、免编译、免重启，天然适配 AI 生成。Powered by magic-api: write HTTP endpoints online, hot-reload, no compile, no restart — ideal for AI generation.

页面即组件文件Pages are component files

页面以 .ms 组件文件存在于 data/magic-api/component/，后端启动时读取并注册为全局组件。改完文件、刷新页面就生效，不需要重新打包。Pages live as .ms component files under data/magic-api/component/; the backend reads and registers them as global components at startup. Edit a file, refresh — no repackaging.

在线管理一切Manage everything online

菜单、角色、用户、字典、模块、配置、图标、页面组件，全部后台可视化维护。Menus, roles, users, dictionaries, modules, config, icons and page components — all maintained in the admin UI.

API 网关 · 开放接口API gateway · Open API

把后端开放出去，接 APP、小程序和第三方系统Expose your backend to apps, mini-programs and partners

内置一套完整的开放接口网关：注册应用 → 换 token → 按接口授权 → 限流 → 留调用日志。外部系统不碰你的后台账号体系，只拿一个应用身份调用被授权的接口。 A built-in open-API gateway: register an app → exchange a token → authorize per endpoint → rate-limit → keep call logs. External systems never touch your admin accounts; they call authorized endpoints with an app identity.

应用注册App registration

为每个接入方建一个应用，拿到 appKey 与 appSecret；secret 可随时重置，停用即刻失效。Create one app per partner with an appKey and appSecret; secrets can be rotated and apps disabled instantly.

token 鉴权Token auth

用 appKey + appSecret 换取 token，之后请求带 Authorization: Bearer <token>，由拦截器统一校验。Exchange appKey + appSecret for a token, then send Authorization: Bearer <token> on every call — validated by a shared interceptor.

按接口授权Per-endpoint grants

授权精确到「路径 + 方法」，还能给单个接口设独立的速率限制——小程序只给读接口，后台管理接口不开放。Grants are scoped to path + method, each with its own rate limit — give the mini-program read-only endpoints and keep admin APIs closed.

# 1. 用 appKey / appSecret 换 token
$ curl -X POST http://localhost:9089/open/app/token \
    -d 'appKey=xxx&appSecret=yyy'

# 2. 带 token 调用被授权的接口
$ curl http://localhost:9089/api/device/list \
    -H 'Authorization: Bearer <token>'

# 未授权 / 超限 / token 失效 → 各自返回对应状态码
# 1. Exchange appKey / appSecret for a token
$ curl -X POST http://localhost:9089/open/app/token \
    -d 'appKey=xxx&appSecret=yyy'

# 2. Call an authorized endpoint with the token
$ curl http://localhost:9089/api/device/list \
    -H 'Authorization: Bearer <token>'

# unauthorized / over limit / expired token → each returns its own status code

配置数据库Configure the database

基线脚本不代劳建库：先用 CREATE DATABASE 建出 gewumind-boot（字符集 utf8mb4），再把 db/init/01-baseline.sql 导入进去 —— 图形化客户端的「运行 SQL 文件」或命令行都行，导入后是 45 张表加平台自带的菜单/角色/字典/页面组件。 No bootstrap script creates the database for you: run CREATE DATABASE for gewumind-boot (charset utf8mb4) first, then import db/init/01-baseline.sql into it — a GUI client's "run SQL file" or the command line both work. You end up with 45 tables plus bundled menus, roles, dictionaries and page components.

支持哪些数据库：目前仅 MySQL 8。发行包里只内置了 mysql-connector-j 一个 JDBC 驱动，建库基线也是 MySQL 语法。 Supported databases: MySQL 8 only. The distribution ships a single JDBC driver, mysql-connector-j, and the baseline schema is MySQL syntax.

要接 PostgreSQL / Oracle / SQL Server，需要自行添加对应驱动依赖，并把 db/init/01-baseline.sql 转成目标方言（表选项、字符集、自增与注释语法均不通用）。 For PostgreSQL, Oracle or SQL Server, add the driver dependency yourself and port db/init/01-baseline.sql to that dialect (table options, charset, auto-increment and comment syntax are all MySQL-specific).

开源仓库Open source

gewumind-boot · 一个仓库，直接可用gewumind-boot · one repo, ready to use

这是承载内核的应用壳工程：内核以 jar 依赖的形式随仓库入库，配置、数据库、脚本工作区各归各位，clone 下来三条命令就能跑起一整套低代码后端。 This is the application shell that hosts the kernel: the kernel ships as a jar dependency inside the repo, with config, database and script workspace in their proper places — three commands from clone to a running low-code backend.

仓库里有什么What's in the repo

  • libs/ 内核 jar（thin jar + pom，标准 Maven 仓库布局，随工程入库）libs/ the kernel jar (thin jar + pom in a standard Maven layout, checked in)
  • data/magic-api/ 接口脚本与页面组件的工作区，改完即生效data/magic-api/ the workspace for API scripts and page components — edits take effect live
  • db/init/01-baseline.sql 建库基线：43 张系统表 + 平台自带菜单/角色/字典/组件数据，自己建库后导入即可db/init/01-baseline.sql the baseline: 43 system tables plus bundled menus, roles, dictionaries and page components — create the database yourself, then import this file
  • src/main/java/ 启动类与少量适配代码，业务逻辑不写在这里src/main/java/ the bootstrap class and a little glue — business logic does not live here
  • scripts/ 启停与证书脚本（Windows 同名 .bat 行为一致）scripts/ start/stop and certificate scripts, with matching Windows .bat equivalents
