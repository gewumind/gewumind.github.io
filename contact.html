License request format

Send the request to gewumind@foxmail.com. Do not change the labels.

After a Creem purchase

Checkout ID: ch_example123456
Order ID: ord_example123
Order Number: ORD-EXAMPLE123
Product ID: prod_example123
Platform: Creem
License request code: GW1|H|0123456789abcdef0123456789abcdef

Creem lookup uses the Checkout ID (starts with ch_), not ORD-... or the product ID. Order ID, Order Number and Product ID are supporting identifiers. Get the license request code from GewuMind Boot → Configuration → License → Copy request. Send the whole GW1|H|... code, not just the 32-character machine code.

After a Mianbaoduo purchase

Mianbaoduo has no custom success page. Sign in, open My Orders / Purchased, open the order details and copy the order number.

Order Number: MB123456789
Platform: Mianbaoduo
License request code: GW1|H|0123456789abcdef0123456789abcdef

No Checkout ID, Order ID or Product ID is needed for Mianbaoduo. Keep labels unchanged, one field per line. If line breaks collapse, use | in the same order.

Refunds

If no license file has been issued, you may request a refund within 7 days of purchase. Once a license file has been issued, sales are final except for duplicate payment, failure to deliver, a material mismatch with the product description, or where required by law. Machine-code changes are not a refund reason.

Include the order ID, purchase platform, and reason in your email.

Privacy requests

To access, correct, delete, or restrict processing of your personal data, email support@gewumind.com. We may ask for information to verify your identity and order.
