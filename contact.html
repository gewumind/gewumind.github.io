License request format

Send the request to support@gewumind.com using exactly this format. Do not change the labels.

Order ID:
Platform: Mianbaoduo / Creem
Version: 1.x / 2.x
Machine code:

If your email client or the product page collapses line breaks, use one line separated by `|` in the same order. The machine code is shown in the product configuration center (32 hexadecimal characters). A missing or changed label may prevent automatic processing. One order covers one machine code and one version line; machine-code changes require a new license.

Refunds

If no license file has been issued, you may request a refund within 7 days of purchase. Once a license file has been issued, sales are final except for duplicate payment, failure to deliver, a material mismatch with the product description, or where required by law. Machine-code changes are not a refund reason.

Include the order ID, purchase platform, and reason in your email.

Privacy requests

To access, correct, delete, or restrict processing of your personal data, email support@gewumind.com. We may ask for information to verify your identity and order.
