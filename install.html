Install GewuMind Boot

Installer v0.1.0 · Linux / Windows / macOS · GUI + CLI

Live demo (English): http://47.117.145.234:34568 · login admin / 123456
The installer handles environment checks, empty-database validation, schema import, JRE bootstrap, service registration, upgrades and uninstall. Download the application and database packages from GitHub or Gitee Releases. The current installer covers 2.3.0.

Choose an installation path

PathBest forClone source?What you need
Direct install Trials, production deployment, running a prebuilt release No The installer plus the matching application and database packages
Custom development Changing the kernel, adding custom capabilities, deep customization Yes git clone gewumind-boot, JDK 17, Maven 3.8+, MySQL 8

Direct installation does not require cloning the source, Maven, or Node. The installer only installs an already-built release; it does not fetch source or compile the kernel for you.

For custom development, start from the source repository: github.com/gewumind/gewumind-boot. Build your own release after changing it; the installer can then install the package you built.

Prerequisites

  • MySQL 5.7+ / 8.0+, MySQL 8 recommended. The database must already exist and be empty.
  • Java 17+. The installer can download Temurin JRE 17, or use --java-home / --jvm-archive.
  • Root on Linux for systemd; Administrator on Windows.
  • At least 2GB free disk space recommended.

Create an empty database first

CREATE DATABASE `gewumind-boot`
  CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

The installer never creates the database and never overwrites a non-empty one. Confirm it has zero tables:

SELECT COUNT(*) FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'gewumind-boot';

Option 1: graphical installer

Linux / macOS:

chmod +x gw-installer-linux-amd64
sudo ./gw-installer-linux-amd64 gui

Windows: double-click gw-installer-windows-amd64.exe, or run as Administrator:

gw-installer-windows-amd64.exe gui

The GUI listens on 127.0.0.1 only and prints a local URL with a token. For a remote server, use an SSH tunnel instead of exposing the installer port to the internet.

Option 2: command line

After downloading the minimal application package and database package, for 2.3.0 Chinese:

sudo ./gw-installer-linux-amd64 install \
  --version 2.3.0 \
  --lang zh \
  --app-package ./gewumind-boot-app-2.3.0-zh-min.tar.gz \
  --db-package ./gewumind-boot-db-2.3.0-zh.tar.gz \
  --install-dir /opt/gewumind-boot \
  --server-port 9089 \
  --db-host 127.0.0.1 --db-port 3306 \
  --db-name gewumind-boot --db-user root

The database password is prompted without echo; you can also provide GW_DB_PASSWORD.

To let the installer fetch both packages through the manifest:

sudo ./gw-installer-linux-amd64 install \
  --version 2.3.0 --lang zh --source auto \
  --db-name gewumind-boot --db-user root

After installation

  • The admin UI defaults to http://server-ip:9089, login admin / 123456.
  • Linux registers a systemd service and enables it at boot.
  • Commercial features are activated via Configuration → Upload license file. Copy the license request code first.
  • For demos, switch to the demo profile; switch back to online before uploading a license.

Upgrade and uninstall

# Back up the database before upgrading
sudo ./gw-installer-linux-amd64 upgrade \
  --version 2.3.0 \
  --app-package ./gewumind-boot-app-2.3.0-zh-min.tar.gz \
  --db-package ./gewumind-boot-db-2.3.0-zh.tar.gz

# Uninstall; keep the database
sudo ./gw-installer-linux-amd64 uninstall

Upgrades keep the license, data and configuration. Uninstall removes the install directory but keeps the database by default.

Verification and notes

Linux has been verified with real install, upgrade and uninstall runs. Windows Service and macOS launchd support is implemented and cross-compiled but has not yet been validated on real Windows/macOS machines. Include the OS version, installer version and logs when reporting an issue.

For all flags and examples: gw-installer --help, gw-installer install --help.
