If the ID is not shown, copy the order ID from your Creem receipt.

2. Copy the license request code

Open the installed GewuMind Boot admin UI and go to Configuration → License. Click Copy request. It produces a code like: 

GW1|H|b63f549d2f23e0193f760ade394f2160

Keep the whole code. Do not send only the 32-character machine code.

3. Send the license request

Email the following to support@gewumind.com:

Order ID: ch_example123456
Platform: Creem
Version: 2.x
License request code: GW1|H|0123456789abcdef0123456789abcdef

Replace the example order ID with your checkout_id (starts with ch_) and replace the request code with the full GW1|H|... code copied from the product.

Email license request

4. Receive and activate

  1. We verify the Creem payment and issue license.json.
  2. You receive it by email, normally within one business day.
  3. In Configuration → License, click Upload license file and select the JSON file.
  4. Activation takes effect immediately; a restart is only needed for services that were already enabled.

What the license covers

  • One machine code; unlimited GewuMind Boot instances on that machine.
  • One year from issuance.
  • Commercial capabilities for the purchased 2.x line, including AI support, knowledge base and H5 support.
  • Offline activation; no vendor connection is required at runtime.
